# Full-Stack Portfolio

Full-stack portfolio with booking and contact features.

## Features

- Portfolio and services
- Booking and email API
- Admin area, SEO sitemap

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/fullstack-portfolio.git
cd fullstack-portfolio
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
